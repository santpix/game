# ENTREPRENEUR — THE GAME

Open-world ecommerce and growth simulation for live events.

## Core idea

- One shared 3D world on the main event screen
- Controller-driven founder character
- Audience participation via QR/mobile voting
- SantPix = Build / ecommerce technology
- Merco = Growth / acquisition
- Dropi = Scale / commerce operations
- AI = cross-game copilot

## MVP stack

Next.js + React Three Fiber + Three.js, with Supabase Realtime planned for audience participation.

## Run

```bash
npm install
npm run dev
```
